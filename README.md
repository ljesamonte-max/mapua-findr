# Mapúa Findr - Campus Lost & Found System

A desktop application designed to streamline and secure lost-and-found reporting across Mapúa University campus grounds.

## Tech Stack
- **Frontend:** Python (Tkinter)
- **Database:** MySQL
- **Driver:** `mysql-connector-python`
- **Configuration:** `python-dotenv`
